## cURL

```bash
curl --request POST \
  --url https://hom.portalgsf.com.br/api/v1/nfse/ \
  --header 'Authorization: JWT <token>' \
  --header 'Content-Type: application/json' \
  --data @examples/lote-nfse.json
```

## Checklist

<Check>Header `Authorization: JWT …`</Check>
<Check>Body é um **array**</Check>
<Check>`cnpjEmit` = `22760852000110` (sem máscara)</Check>
<Check>`idNfErp` preenchido (equivale a `codigoOrigem` / `cod_origem`)</Check>
<Check>Após `200`, guardar `nroProtocolo` e consultar o retorno</Check>
