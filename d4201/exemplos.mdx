Estes exemplos são sintéticos e foram descritos para a normalização do contrato. Documentos e chaves não representam pessoa, empresa ou evento oficialmente autorizado. Substitua `empresa_id` por uma empresa autorizada para o usuário do JWT e forneça chaves reais da origem na operação efetiva.

Arquivos no repositório:

- `examples/d4201-original-virtual.json`
- `examples/d4201-presencial-pdv.json`
- `examples/d4201-devolucao.json`

## ORIGINAL virtual com CPF

```json
{
  "versao": 1,
  "empresa_id": 10,
  "origem": "ERP_APOSTAS_SINT",
  "competencia": "2026-11",
  "finalidade": "ORIGINAL",
  "grupos": [
    {
      "id_origem": "G-SINT-ORIG-001",
      "chave_dere": "12345678901AAAAAAAAAAAAAAAAAAAAAAAA202611050500000001",
      "presencial": false,
      "apostador": {
        "cpf": "52998224725",
        "municipio": "3550308"
      },
      "operacoes": [
        {
          "data_hora": "2026-11-05T12:00:00.000+00:00",
          "valor": "100.00"
        }
      ]
    }
  ]
}
```

## ORIGINAL presencial no PDV

Município na operação, porque a borda REST não aceita `ponto_venda.municipio`.

```json
{
  "versao": 1,
  "empresa_id": 10,
  "origem": "ERP_APOSTAS_SINT",
  "competencia": "2026-11",
  "finalidade": "ORIGINAL",
  "grupos": [
    {
      "id_origem": "G-SINT-PDV-001",
      "chave_dere": "12345678901CCCCCCCCCCCCCCCCCCCCCCCC202611050500000003",
      "presencial": true,
      "ponto_venda": {
        "cnpj": "11222333000181"
      },
      "operacoes": [
        {
          "data_hora": "2026-11-05T15:30:00.000-03:00",
          "valor": "50.00",
          "municipio": "3550308"
        }
      ]
    }
  ]
}
```

## DEVOLUCAO

Estrutura apenas. A recepção depende de um original oficialmente aprovado, com recibo real e sequência `001` existente. O exemplo não satisfaz essa conferência sozinho.

```json
{
  "versao": 1,
  "empresa_id": 10,
  "origem": "ERP_APOSTAS_SINT",
  "competencia": "2026-11",
  "finalidade": "DEVOLUCAO",
  "grupos": [
    {
      "id_origem": "G-SINT-DEV-001",
      "chave_dere": "12345678901BBBBBBBBBBBBBBBBBBBBBBBB202611050500000002",
      "chave_referencia": "12345678901AAAAAAAAAAAAAAAAAAAAAAAA202611050500000001",
      "presencial": false,
      "apostador": {
        "cpf": "52998224725",
        "municipio": "3550308"
      },
      "operacoes": [
        {
          "data_hora": "2026-11-05T18:00:00.000+00:00",
          "valor": "100.00",
          "sequencia_referencia": "001"
        }
      ]
    }
  ]
}
```

<Tip>
Para cancelar, reuse a estrutura da devolução com `"finalidade": "CANCELAMENTO"`.
</Tip>
