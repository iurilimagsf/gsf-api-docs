```http

Content-Type: application/json
```

## Variações

| Objetivo | Ajuste no JSON |
| --- | --- |
| NF-e de entrada | `isNfeIde.tpNf = "0"` |
| Ambiente de produção no documento | `isNfeIde.tpAmb = "1"` |

<Tip>

</Tip>
