## cURL

```bash
curl --request POST \
  --url https://hom.portalgsf.com.br/api-boss/v01/emissaoDCe/ \
  --header 'Authorization: JWT <token>' \
  --header 'Content-Type: application/json' \
  --data @examples/dce-emissao.json
```

## Checklist

<Check>Header `Authorization: JWT …`</Check>
<Check>Body é um **objeto** (não use `Lote` nem array raiz)</Check>
<Check>`emit.CNPJ` válido, somente dígitos</Check>
<Check>`det` com pelo menos um item (`xProd`, `qCom`, `vUnCom`)</Check>
<Check>Destinatário com CNPJ **ou** CPF (não os dois)</Check>
<Check>`tpEmit = 3` exige CNPJ da transportadora</Check>
<Check>Após o envio, consultar com a mesma `chave_dce` em `/api-boss/v01/consultaDCe/`</Check>
