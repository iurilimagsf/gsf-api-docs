Todas as operações de DC-e exigem um token JWT. Apenas a emissão do token é anônima.

## Obter o token

```http
POST /api-boss/api-token-auth/
Content-Type: application/json
```

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `username` | string | Sim | Usuário da conta de integração |
| `password` | string | Sim | Senha da conta |

```json
{
  "username": "<usuario_integracao>",
  "password": "<senha>"
}
```

Homologação: `https://hom.portalgsf.com.br/api-boss/api-token-auth/` · Produção: conforme o ambiente do cliente.

### Resposta `200`

```json
{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}
```

## Usar o token

```http
Authorization: JWT eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
```

<Warning>
Não utilize `Bearer`. O valor correto começa com `JWT`, seguido de um espaço e do token.
</Warning>

## Validade

| Item | Valor |
| --- | --- |
| Algoritmo | HS256 |
| Validade | 24 horas |
| Refresh | Não disponível |
| Renovação | Nova chamada a `/api-boss/api-token-auth/` |

Ao receber `401`, descarte o token atual, autentique novamente e repita a operação **uma vez**.

## Exemplos

<CodeGroup>

```bash
curl --request POST \
  --url https://hom.portalgsf.com.br/api-boss/api-token-auth/ \
  --header 'Content-Type: application/json' \
  --data '{
    "username": "<usuario_integracao>",
    "password": "<senha>"
  }'
```

```python
import requests

r = requests.post(
    "https://hom.portalgsf.com.br/api-boss/api-token-auth/",
    json={"username": "<usuario_integracao>", "password": "<senha>"},
    timeout=30,
)
r.raise_for_status()
headers = {"Authorization": f"JWT {r.json()['token']}"}
```

```javascript
const res = await fetch(
  "https://hom.portalgsf.com.br/api-boss/api-token-auth/",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      username: "<usuario_integracao>",
      password: "<senha>",
    }),
  }
);
const { token } = await res.json();
const auth = `JWT ${token}`;
```

</CodeGroup>

## Try-it

1. Abra **API Playground → Obter token JWT (DC-e)**.
2. Informe usuário e senha de homologação.
3. Copie o valor de `token`.
4. No campo **Authorization**, cole `JWT ` + token (com espaço).
5. Execute emissão e consulta na mesma aba.

O playground usa a homologação GSF (`hom.portalgsf.com.br`) com proxy do Mintlify.
