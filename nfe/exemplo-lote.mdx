## cURL

```bash
curl --request POST \
  --url https://hom.portalgsf.com.br/api/v1/nfe/ \
  --header 'Authorization: JWT <token>' \
  --header 'Content-Type: application/json' \
  --data @examples/lote-nfe.json
```

## Checklist

<Check>Raiz do JSON é `{ "Lote": [ ... ] }`</Check>
<Check>`indProdServ` = `P` para produto (mercadoria)</Check>
<Check>`codigoOrigem` único por documento</Check>
<Check>CNPJ sem máscara: `22760852000110`</Check>
<Check>Datas em `DD/MM/AAAA`</Check>
<Check>Após o envio, consultar com o mesmo `codigoOrigem` em `/api/v1/nfe/consulta/`</Check>
